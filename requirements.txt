# NOTES

# 1. GPU is optional. Only the embedding step benefits meaningfully; every other
#    step runs comfortably on CPU.
#

#    harmless and the model downloads correctly. It is deliberately not pinned
#    to 1.x, which was not part of the verified configuration.
#
# 3. The original 2023 version of this tutorial installed `perch` (formerly
#    `chirp`) at a pinned commit. That package can no longer be installed: it
#    requires Python <3.12, and its dependencies are mutually unsatisfiable
#    (flax needs numpy>=1.26 while numba needs numpy<1.25). `perch-hoplite` is
#    the maintained replacement from the same team.
#
# 4. Audio and the pre-trained model download automatically from public sources
#    (Google Cloud Storage and Kaggle Models). No Google Drive access, no
#    credentials, and no manual setup are required.
